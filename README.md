Sistema de Estoque em Java 

Este é um projeto desenvolvido para praticar os fundamentos da Programação Orientada a Objetos (POO) em Java. O sistema permite gerenciar produtos de forma dinâmica.

  Funcionalidades
- Cadastro de Produtos: Adiciona nome, preço e quantidade inicial.
- Armazenamento Dinâmico: Utiliza `ArrayList` para manter os produtos em memória durante a execução.
- Controle de Vendas: Permite localizar um produto pelo nome e subtrair unidades do estoque.
- Listagem Completa: Exibe todos os itens cadastrados e seus status atuais.

  Tecnologias Utilizadas
- Scanner API: Para interação via terminal.
- ArrayList: Para manipulação de coleções de objetos.
